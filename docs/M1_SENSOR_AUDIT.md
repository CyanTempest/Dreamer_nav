# M1（ZGWS）机载传感器与碰撞包络核对

R10 用于冻结 v9 山路导航。坐标为机身 FLU（前、左、上），位置单位 m；“离地”以站立接触面为基准。MATRiX 的位置以 base_link 为基准，UE 的旋转参数按包内约定解释。表中运行数据均来自已存点云、关节位形或本次服务器 CPU 计算。未在机器人或 Colab 上重新采集。

## 双 Airy

MATRiX v1.1.2 的主配置初始 sensors 为空。其 SENSORS_CN.md 将双 Airy 和四鱼眼加双 Airy 列为两套可选预设。下表的“双雷达”是 config_dual_airy_gpu.json，经 ZGWS 的 stair2/config.json 实际加载；“环视”是 config_surround4_airy_calibration_approx.json。不能将二者混作一个出厂外参。

厂商依据见 [RoboSense Airy 手册及附录逐通道表](https://robosense-robotics.github.io/product-manual/en/Airy/)。nav3/calibration.py 旧脚本中另有 base_ground_height_assumed_m=0.54；它是旧假设。R10 取用户给定的传感器平均绝对高和实测双机相对外参。

**数据复核。** clouds.py 按小端 XCDR1 消息中的 fields、row_step 和 point_step 解码了 5 个原始样本。每点 26 B，ring 为偏移 16 的 uint16，timestamp 为偏移 18 的 float64。stair2 首帧前/后分别有 57,552 / 46,339 个有限且距离 >0.1 m 的点，点内时间跨度均为 0.099988 s。fullactive 两个首帧均为 860×96。direct_drive 首帧的逐点时差为零。原始 frame_id 写 map，包内 LidarCameraProjection_CN.md 明确 XYZ 是传感器局部 FLU。ARY1 二进制布局按头部计数、文件长度、所有方向的单位长度、ring 顺序及采集回波交叉核验；模板方向分布与厂商标称之间的差异没有作为实机标定量使用。

从 direct_drive 原始里程计按约 0.20 s 窗口差分，forward 阶段速度峰值 0.457 m/s，turn 阶段角速度峰值 0.425 rad/s。stair2 的 track 阶段 3,194 个同阶段窗口中，两项 P95 为 1.163 m/s、0.417 rad/s，峰值 1.221 m/s、0.614 rad/s。用这些观测检验限速口径时，nav4 的 0.8 m/s 应读作保守命令范围。时间窗口重叠，速度为净位移差分；完整分阶段结果在 speeds.json。

尺寸与速度来源见 [智身科技铜锤 M1](https://zsibot.com/M1)。physical.py 用 MuJoCo CPU 前向运动学变换每个启用碰撞的 mesh 顶点或有向盒顶点，共 13 个几何体。统一以水平 base 和最低接触点为基准计算尺寸；排除视觉网格。home 的 XML base 高度与站姿实际接触基准分开。五组 qpos 来自 matrix_v4_val/results/vm/stairs_standing.json，是已存仿真位形。静态包络没有覆盖全部运动姿态的证明。

## 栅格近似和未知横带

- 2.5D 地平线以 256 个水平角（1.40625°）和 64 个 0.125 m 径向格合成。8 m 处角向格宽约 19.6 cm；Airy 原生名义 0.4° 在相同距离的弧宽约 5.6 cm。原生方位绕雷达轴，地平线方位绕竖直轴。两个方位格的数量不能直接当作相同坐标轴的抽样倍率。
- 六个真实回放位姿，单帧、相机开启，地平线从 256×64 加密到 900×128、径向格长减半。可见比例由 19.95% 变为 18.09%，2.36% 的 BEV 格改变可见性。
- 同六姿态，相机关闭，用完整旧实测旋转矩阵、每台 96×900 条厂商标称射线、0.025 m 步长分别穿过地面与六个有覆盖的 atlas 带。v2 覆盖 19.03%，逐射线参考覆盖 26.91%；12.52% 的格判定不同，其中 10.20% 仅逐射线可见，2.32% 仅 v2 可见。参考步长从 0.05 m 减半时，其掩码自身改变 1.88%。这些差异同时包含方位离散、有限格和遮挡几何口径。顶面地平线把悬空枝叶下面也当作遮挡；这是 v2 的一项保守近似。均为地图模拟对照，缺少同位姿实机点云验证。
- 另用 MATRiX ARY1 第二个完整帧的 86,400 个实际方向替换理想化方向，保持同一安装位姿、地图和 0.025 m 步长。模板射线覆盖 20.19%，v2 覆盖 19.03%，逐格异或 13.30%，其中 6.08% 仅 v2、7.23% 仅模板射线可见。汇总覆盖率接近仍会掩盖空间分布差异。数据见 dense_matrix.json。
- 对旧视频对应的全部 8,326 个已交付 BEV，x=−1.1875 m 这一行全宽未知为 0 帧，平均 5.85% 未知，单帧最高 51.56%。冷启动全宽未知实际出现在 x=−0.3125 至 +0.3125 m。无噪声平地试验去掉矩形机体掩码仍为 6 行；将双雷达原点在诊断中重合后为 0 行。v2 对格子与最外波束的交集做判断，真实安装不动，全宽未知缩成 4 行。剩下的横带位于朝前/朝后的半球视野之间，行进后由有效历史回波逐渐覆盖。

数值证据位于服务器 audit_20261116/nav4_r10 下的 body.json、airy.json、clouds.json、band.json、seam.json、paired_bev.json 和 dense_rays.json。六站点配对图为同目录 paired_bev.png。
