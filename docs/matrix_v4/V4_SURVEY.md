# Dreamer 4 底座选择与 A 段训练预算

**选型**　采用 Nicklas Hansen、Xiaolong Wang 的 [MMBench2 源码](https://github.com/nicklashansen/mmbench2/tree/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9)，对应 2026 年论文 *Hallucination in World Models is Predictable and Preventable*。旧仓库把“严格更好”限定在其新实现、训练配方、数据和模型规模上。新库能训练连续动作条件的世界模型和行为克隆（BC）头。适合先做双 Airy BEV 闭环，再单独验证想象 RL。本文的“源码”与“论文结果”分别来自固定提交和作者报告，本项目尚无 A100 训练或 MATRiX 闭环实测。[旧库公告](https://github.com/nicklashansen/dreamer4/blob/b8abafbf4da72c59b6aa09f8499ccde0d6a37fd6/README.md#L3-L11) · [新库发布说明](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/README.md#L3-L19) · [论文](https://arxiv.org/abs/2606.27326)

### 从数据到策略

1. **Tokenizer 预训练**用时间因果的遮挡自编码重建。默认 masked MSE + RGB LPIPS；BEV 禁用 LPIPS（`lpips_weight=0`），逐通道报告地面高度和年龄误差、障碍/支撑/未知区的分类误差。路线通道按 v1 的 route-free 编码验零，别让恒零通道改善平均分。[损失](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/train_tokenizer.py#L591-L620) · [v1 通道](../../nav4/env.py#L407-L419)
2. **动力学预训练**冻结 tokenizer，在打包后的 latent 上拟合带连续动作条件的 shortcut flow matching。经验数据提供预测目标，后期开启半步自一致 bootstrap。默认启动点 10,000 步，短试验须下调，否则全程不会训练该分支。[冻结](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/train_dynamics.py#L227-L238) · [目标](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/train_dynamics.py#L323-L357) · [默认值](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/train_dynamics.py#L1832-L1839)
3. **带奖励与策略头的微调**沿用动力学入口，`n_agent>0, reward_weight>0, bc_weight>0`，默认这三项为零。reward 为 symlog two-hot，多步预测；BC 对 agent feature 做 detach，梯度只更新 BC 头。动力学/奖励学习仍可更新 backbone。碰撞、偏离、随机段适合 WM 和 reward；BC 标签应来自同时保存的干净教师速度或经过筛选的教师段，不能把注入噪声当成正确动作。[头开关](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/train_dynamics.py#L1283-L1321) · [损失](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/train_dynamics.py#L364-L457) · [作者说明的梯度差异](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/model.py#L810-L827)
4. **计划与想象 RL**　作者以 BC 热启动 CEM 在模型内采样，再闭环评估，另有 `plan_cem.py` 的 latent 终点代价实验。该提交只含 tokenizer、dynamics 两个训练脚本，没有 value、returns、actor 的想象优化入口。单纯在预测模型里采样，或用 CEM 选择动作，都不能算完成该阶段。后续须补可采样的连续策略（例如有界 squashed Gaussian）、value、continue/终止、短 rollout、TD(λ) 与策略更新，并以冻结 BC 行为作约束及对照。[源码树](https://github.com/nicklashansen/mmbench2/tree/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src) · [CEM 程序](https://github.com/nicklashansen/mmbench2/blob/3dda6ea5bc60382ad9e1dcd1c6c3af67d69326a9/src/plan_cem.py#L1-L24) · [论文附录 F 表 12](https://www.nicklashansen.com/mmbench2/paper.pdf)

## A 段 MVP 与后续投入（设计估算）

**范围**　从全新权重训练单任务 BEV tokenizer、动力学、reward 与 BC，在 MATRiX 以 5 Hz 执行 BC 头，比较 V3 教师和直接 BEV→速度 BC。先保留失败轨迹并在实仿核对收益。原 RGB 权重的输入投影、patch 数量和 BEV 物理语义均已改变；首轮不安排 RGB 权重迁移。

| 优先项 | 实施与验收办法 | 工程估算 |
|---|---|---|
| 数据适配 | 每回合 N 个转移、N+1 个观测。按 episode 和路线窗口/起点分组切分，再取连续窗。替换两套上游 loader、固定任务列表和 domain 统计；训练和验证显式 H/W/C，HWC→CHW 只执行一次；记录覆盖来源、终止/截断、干净教师及实际速度。用两条合成轨迹验时序和零 padding。 | 1–2 人日 |
| BEV tokenizer | 64×64×6、patch 8（8×8 个图块），width 128、depth 4、4 头，8 个 32 维 latent。保留 v1 字节流，训练时统一除 255。屏蔽恒零走廊的重建权重。输出各通道指标与最后帧复制基线。 | 0.5–1 人日 |
| 动力学与策略 | width 256、depth 6、8 头、packing 2（每帧 4 个空间 token），1 个 agent token。固定单任务条件，BC 只用第一有效步或 L=1；成功/失败都监督 reward 和新增 continue 头。加入带位置掩码的回合尾，区分真终止与超时。先改从零启动的 `resume=None` 和明确的续训逻辑（上游默认路径不存在时会直接读取失败）。关闭上游 **两处显式在线** W&B 初始化，图像和权重只写本地，按工程同步方案拉回。 | 1.5–2.5 人日 |
| 回放与闭环 | 同种子 A 段窗口，按起点、失败类型分层评估。报告 1/5/10 步预测对复制基线的改善、正确动作与打乱动作的误差比、各轴 BC 误差、奖励/终止校准；线上比较到达距离、协助/100 m、严格/≤3 次协助成功率、指令时延的 p95/p99。若动作打乱无影响或仅像素分数好，先修数据/动作同步。 | 1–2 人日 |

**单 A100 时间盒**　先准备 2万–5万条 5 Hz 转移（1.1–2.8 仿真小时，单实例实时折算，不计重置和丢帧），分层含专家、扰动和真实失败。采集结束、仿真退出再训练。BF16，T=16、微批 8、累积 1，形状固定；先将 WM bootstrap_start 设 300 步、warmup 100 步。拟定上限分别为 tokenizer 2k、动力学 3k、头微调新增 1k 步。已恢复阶段按累计步数设置上限。预算 4 小时中分配 50/90/45 分钟给三段，剩余 55 分钟给预热、验证、同步和停止。每段先计 100 步端到端吞吐与峰值显存（动力学开启 bootstrap 后复测），按剩余秒数除以实测秒/步缩减其余更新；每 5 分钟落盘。显存不足先降 B 到 4，增加累积时以优化器更新而非微批计数。4 小时能交付的是限时训练、留出指标和可恢复产物；达到预定步数、显存峰值和策略通关率都需 A100 实测。取得真实速度后再决定是否投入想象 RL。
